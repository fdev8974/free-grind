# Demo profile pictures

Pictures in this folder replace every profile photo when **Settings → Developer → Demo Profile Pictures** is on, so screenshots don't show real people. Each profile always gets the same picture.

- Use AI-generated people only, never photos of real persons.
- Square, about 480×480, `.webp` (or `.jpg`, `.png`, `.avif`), ideally under 50 KB each: they're bundled into the app and every OTA update.
- Any file name works; around 30 pictures avoid obvious repeats in the grid.

The toggle only appears in the developer settings once this folder contains at least one picture.
