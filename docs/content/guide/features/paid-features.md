# Paid feature bypass

Some actions are only allowed on a paid Grindr subscription. When Grindr refuses one of them, Free Grind can try to get it through anyway:

- Sending more than one expiring photo per day
- Unsending a message
- Sharing an album
- Messages that Grindr only allows with a subscription

## How it works

Grindr decides which paid features a session gets based on the location it reports. In some countries, such as Honduras, these features are free. When Grindr refuses a paid feature, Free Grind offers to switch your location to Honduras for a moment, retry the action, and switch back.

Background on this and other bypasses is collected on Open Grind's [Grindr API bypasses](https://opengrind.org/guides/bypasses) page.

::: danger Use at your own risk
This violates Grindr's terms of service and can get your account banned. Free Grind always asks before using it.
:::

Expiring albums are a paid feature with no known bypass.
