# Chat translation

Free Grind translates chat messages into your app language, one message at a time from the message menu, or automatically for a whole chat.

Set it up in **Settings → Translation**. You need an API key from one of these providers. The key is stored only on your device and sent only to that provider.

| Provider         | Notes                                                                                     |
| ---------------- | ----------------------------------------------------------------------------------------- |
| Google Translate | Fast, literal machine translation. Often misses slang and abbreviations. The first 500,000 characters per month are free. |
| Gemini           | AI translation that understands gay dating slang, abbreviations and context. Free tier with daily limits. |
| ChatGPT (OpenAI) | AI translation that understands slang and context. Paid per use, a message costs a fraction of a cent. |
| Claude (Anthropic) | AI translation that understands slang and context. Paid per use, the most expensive option. |

The translation settings walk you through creating a key for each provider, step by step.

::: tip
On Gemini's free tier, Google may use your messages to improve its products. With billing enabled, it doesn't.
:::
