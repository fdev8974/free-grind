# Automation

**Settings → Automation** handles new chats for you, so you don't have to deal with the same messages over and over.

## Auto-block

- **Age limits:** block anyone outside an age range.
- **Forbidden keywords:** block anyone whose first message contains a word from your list.
- **Apply to inbox:** also block existing new chats that match, right away.

## Custom rules

Build your own "when X then Y" rules for someone's first message to you. A rule checks the sender, then:

- blocks them,
- replies with a message,
- shares one of your albums, or
- sends a tap (only if you haven't tapped them yet, at most once a day, after a short random delay).

Each rule runs once per new chat.
